# Sistema de Gestión de Estudiantes

## Descripción del proyecto

Esta aplicación fue desarrollada en Java y permite capturar los datos de un estudiante, mostrar su información y verificar si aprobó una materia de acuerdo con su calificación.

## Objetivo

Aplicar los conceptos básicos de la programación orientada a objetos mediante la creación de clases, atributos, objetos, constructores y métodos.

## Funcionalidades

- Capturar la matrícula del estudiante.
- Registrar su nombre.
- Ingresar su calificación entre 0 y 100.
- Validar que la calificación ingresada sea correcta.
- Mostrar los datos del estudiante.
- Indicar si el estudiante aprobó o no aprobó, considerando 70 como calificación mínima aprobatoria.

## Estructura del proyecto

- **Estudiante.java:** contiene los atributos del estudiante, el constructor y los métodos para mostrar su información y comprobar si aprobó.
- **Main.java:** contiene el método principal, solicita los datos al usuario, crea el objeto y muestra los resultados.

## Tecnologías utilizadas

- Lenguaje de programación Java.
- JDK 25.
- Visual Studio Code.

## Ejecución

Abre el proyecto en Visual Studio Code y ejecuta el archivo `Main.java`. Después, ingresa la matrícula, el nombre y una calificación válida para consultar el resultado.
