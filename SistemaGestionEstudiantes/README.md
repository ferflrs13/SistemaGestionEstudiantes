
# Sistema de Gestión de Estudiantes

## Descripción
Aplicación desarrollada en Java para administrar información
básica de estudiantes y comprobar si aprobaron una materia.

## Objetivo
Aplicar los conceptos de programación orientada a objetos:
clases, atributos, objetos, constructores y métodos.

## Características
- Registro de matrícula.
- Almacenamiento del nombre del estudiante.
- Registro de calificaciones.
- Consulta de información.
- Verificación de aprobación con calificación mínima de 70.

## Clases utilizadas
- Estudiante.java: define los atributos, constructor y métodos.
- Main.java: crea los objetos y ejecuta el programa.

## Tecnologías
- Java JDK 25.
- Visual Studio Code.

## Ejecución
Abrir el proyecto en Visual Studio Code y ejecutar Main.java.
